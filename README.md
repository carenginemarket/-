# carenginemarket

Single-page SEO article site targeting the keyword **engine rebuild vs engine replacement**.

## Files
- `index.html` – full page (luxury dark-emerald and gold theme, animated hero, 1000+ word article, SVG images, FAQ schema)
- `robots.txt` – crawler rules and sitemap location
- `sitemap.xml` – sitemap for the homepage
- `README.md` – this file

## Setup
1. Replace `https://carenginemarket.com/` with your real domain in `index.html`, `robots.txt` and `sitemap.xml`.
2. Upload all files to the site root.
3. Submit `sitemap.xml` in Google Search Console.

## Notes
- The anchor text "best petrol engines" appears once, in the second paragraph, linking to https://enginesmarket.co.uk/.
- No phone number or call button is included.
